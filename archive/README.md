Moved on 2026-10-10. The files were not rewritten.

## Why

v1 and v2 were primitive. The idea was to use AI to research a topic and also condense that research into study material: foundations, techniques, checklists, concept maps, and judge/refine loops.

That fantasy was badly implemented. Combining studying and research was a bad idea.

Research needs rare sources, and proof the page is real. Study needs a learner, a map, practice, and a test. One skill that tries to do both does both badly.

- v1 put search, writing, judging, and studying in one session. It filled the context with sources, then wrote long "mastery" pages. Those pages looked like a study system. They were not one.
- v2 added scouts, writers, judges, gates, and token logs to make the same idea cheaper. More machinery did not fix the idea. It still researched and studied in one pipeline.

Study is a separate pipeline: <https://github.com/mccleod1290/Study-OS>

This repo keeps one job. The live skill is `skills/research/SKILL.md`. It hunts niche blogs. It does not write the study.

`archive/v3-draft/` is a later scoring draft. It is not the skill either. Do not run it.
