# Research Skill

This repo finds niche blogs for specialized security research. It does not teach the topic.

Study is a separate pipeline: [Study-OS](https://github.com/mccleod1290/Study-OS).

The live skill is [`skills/research/SKILL.md`](skills/research/SKILL.md). Agents follow [`AGENTS.md`](AGENTS.md).

Deep research is for a niche in offensive security, AI security, or vulnerability research. General learning, such as Azure architecture, is not a research run.

v1 and v2 tried to research and study in one workflow. That failed. They are in [`archive/`](archive/README.md), unchanged. A later draft of v3 is in [`archive/v3-draft/`](archive/v3-draft/README.md). Do not run either.

## Prompt

```text
research niche blogs on cache keys that drop the Authorization header
```
